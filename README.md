## 1. Project Overview
This report documents a **basic system security audit** performed on a Windows device. The goal was to check the following areas for proper security:

- **Password Strength**
- **Firewall Status**
- **Software Updates**

Screenshots are included as evidence of the checks.

---

## 2. Security Audit Checklist

### 2.1 Password Strength
- Reviewed the **Sign-in options** on Windows.
- Ensured passwords are strong with:
- Uppercase and lowercase letters
- Numbers
- Symbols
- Verified password management options are available.
- **Recommendation:** Always use **unique and complex passwords** for all accounts.

### 2.2 Firewall Status
- Checked **Windows Firewall** for all network types (Domain, Private, Public).
- Confirmed firewall is **enabled** and active.
- **Recommendation:** Keep the firewall **enabled at all times** to protect against unauthorized access.

### 2.3 Software Updates
- Checked **Windows Update** for available system updates.
- Device has reached **end of support** and is no longer receiving security updates.
- **Recommendation:** Upgrade to a **supported Windows version** to continue receiving updates and security patches.

## 3. Summary of Findings
- **Passwords:** Settings verified, strong passwords recommended.
- **Firewall:** Enabled on all networks, protecting against unauthorized access.
- **Software Updates:** System is no longer supported; upgrading recommended.

---

## 4. Recommendations
1. Use **strong, unique passwords** for all accounts.
2. Keep the **firewall enabled** at all times.
3. **Upgrade to a supported Windows version** to receive security updates.
4. Enable **automatic updates** for all critical software.
