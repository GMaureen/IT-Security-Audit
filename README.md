## 1. Project Overview
This report documents a **basic system security audit** performed on a Windows device.

The audit focused on evaluating the following areas to ensure proper security:
- **Password Strength**
- **Firewall Status**
- **Software Updates**

The purpose of this audit is to **identify potential vulnerabilities** and provide **recommendations for improving system security**.

Screenshots have been included as evidence of the checks performed.

---

## 2. Security Audit Checklist

### 2.1 Password Strength
- Reviewed the **Sign-in options** on Windows.
- Ensured passwords are strong, including:
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols
- Verified that password management options are available.

**Recommendation:**
- Always use **unique and complex passwords** for all accounts to reduce the risk of unauthorized access.

### 2.2 Firewall Status
- Checked **Windows Firewall** for all network types:
- Domain
- Private
- Public
- Confirmed that the firewall is **enabled** and actively protecting the system.

**Recommendation:**
- Keep the firewall **enabled at all times** to prevent unauthorized access.

### 2.3 Software Updates
- Checked **Windows Update** for available system updates.
- Device has reached **end of support** and is no longer receiving security updates.

**Recommendation:**
- Upgrade to a **supported Windows version** to continue receiving updates and security patches.
- Enable **automatic updates** for all critical software to ensure the system remains secure.

## 3. Summary of Findings
- **Passwords:** Settings verified; strong passwords recommended.
- **Firewall:** Enabled and protecting the system.
- **Software Updates:** System is no longer supported; upgrading recommended.

---

## 4. Recommendations
1. Use **strong, unique passwords** for all accounts.
2. Keep the **firewall enabled** at all times.
3. **Upgrade to a supported Windows version** to receive security updates.
4. Enable **automatic updates** for all critical software.
5. Regularly review security settings to ensure ongoing protection.
